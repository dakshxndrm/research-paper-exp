Contiv provides configurable [networking](/definition/application_exposure_service_and_ingress.md) (native L3 using BGP, overlay using vxlan, classic L2, and Cisco-SDN/ACI) for various use cases and a rich policy framework. The installer provides both kubeadm and non-kubeadm based installation options. The Contiv project is fully open sourced.
