kube-router is an open source turnkey solution for Kubernetes [networking](/definition/application_exposure_service_and_ingress.md) with the aim to provide operational simplicity and high performance. It leverages the Kubernetes API, BGP, and Golang for the control path and Linux networking primitives for the data path. It provides a low overhead alternative and is used in both k0s and k3s.
