[Addons](/definition/cluster_addons.md) extend the functionality of Kubernetes. Important examples include DNS for cluster-wide DNS resolution, Web UI (Dashboard) for [cluster management](/definition/control_plane_components.md) via a web interface, Container Resource Monitoring for collecting and storing container metrics, and Cluster-level Logging for saving [container logs](/operations/kubectl_debugging_operations.md) to a central log store.
