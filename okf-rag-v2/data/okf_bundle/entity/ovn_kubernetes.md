[OVN-Kubernetes](/definition/windows_network_driver_descriptions.md) is a [networking](/definition/application_exposure_service_and_ingress.md) provider for Kubernetes based on OVN (Open Virtual Network), a virtual networking implementation that came out of the Open vSwitch (OVS) project. It provides an overlay based networking implementation for Kubernetes, including an OVS based implementation of [load balancing](/component/service_load_balancing.md) and network policy.
