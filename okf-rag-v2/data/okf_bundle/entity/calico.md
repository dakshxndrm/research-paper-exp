Calico is a [networking](/definition/application_exposure_service_and_ingress.md) and network policy provider. It supports a flexible set of networking options so you can choose the most efficient option for your situation, including non-overlay and overlay networks, with or without BGP. Calico uses the same engine to enforce network policy for hosts, pods, and (if using Istio & Envoy) applications at the [service](/component/service_load_balancing.md) mesh layer.
