If you are running a Kubernetes cluster on your own hardware or a different cloud provider, consult your documentation for security best practices. Kubernetes provides links to security documentation for Alibaba Cloud, Amazon Web Services, Google Cloud Platform, Huawei Cloud, IBM Cloud, Microsoft Azure, Oracle Cloud Infrastructure, Tencent Cloud, and VMware vSphere.
