[Gateway](/api_kind/gateway_resource.md) allows for [custom resources](/design_principle/portable_specifications.md) to be linked at various layers of the API. This extensibility makes granular customization possible at the appropriate places within the API structure, supporting the role-oriented nature of organizations.
