The Develop lifecycle phase focuses on ensuring the integrity of development environments and designing applications following good practices for information security appropriate for the context. Key practices include adopting an architecture such as zero trust that minimizes attack surfaces, defining a code review process that considers security concerns, building a threat model of the system to identify trust boundaries and risks, and incorporating advanced security automation such as fuzzing and security chaos engineering where justified.
