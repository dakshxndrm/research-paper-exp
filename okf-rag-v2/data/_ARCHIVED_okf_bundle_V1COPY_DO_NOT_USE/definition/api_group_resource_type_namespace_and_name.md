[Kubernetes](/policy/garbage_collection_in_kubernetes.md) uniquely identifies objects using a combination of four attributes: * **[API group](/entity/api_group.md)** (e.g., `apps`) * **[Resource](/resource/cluster_resources.md) type** (e.g., `deployments`) * **Namespace** (for namespaced resources) * **Name**
