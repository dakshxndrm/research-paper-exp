A PriorityClass is a cluster-scoped API object that maps a [priority class](/entity/priorityclass.md) [name](/definition/api_group_resource_type_namespace_and_name.md) to an [integer priority](/metric/priority_value.md) value. Higher numbers indicate higher priority.
