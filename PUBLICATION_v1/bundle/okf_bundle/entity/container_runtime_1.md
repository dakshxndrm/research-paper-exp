[Kubernetes](/policy/garbage_collection_in_kubernetes.md) relies on a [container runtime](/entity/container_runtime.md) to set up and run containers. The Kubernetes project does not recommend a specific [container runtime](/definition/kubernetes_node_components_overview.md), and you should make sure that the runtime(s) you choose meet your information security needs.
