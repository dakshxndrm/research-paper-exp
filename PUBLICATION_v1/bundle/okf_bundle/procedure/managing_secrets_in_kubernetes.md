To manage secrets in [Kubernetes](/policy/garbage_collection_in_kubernetes.md), you can use the `[kubectl](/tool/kubectl_command_line_tool.md)` command-line tool to create and update secret objects. These objects can be used to store sensitive information such as passwords or API keys.
