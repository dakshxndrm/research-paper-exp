[RuntimeClass](/entity/runtimeclass.md) is a feature for selecting the [container runtime configuration](/procedure/configure_cri_implementation_on_nodes.md). It allows you to set different [runtime](/entity/container_runtime_1.md) configurations between different [Pods](/definition/kubernetes_cluster_architecture.md).
